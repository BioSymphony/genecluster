# Plant Metabolic Network and P450 references

**Status:** mixed. PMN 17 is current as of 2026-08-30 and remains subject to provider access and redistribution terms. P450 reference resources must be checked at their current public source before use.

These resources can help map candidate enzymes to curated pathway steps or P450 reactions. They are reference evidence, not ground truth for a new species.

## Access boundary

Obtain PMN data through the provider's current download and license process. Do not commit, mirror, or redistribute gated data in this repository. Record the release, access date, provider identifier, and allowed use in the database ledger.

Public examples should use stable identifiers and tiny synthetic rows rather than copied provider datasets.

## Output contract

Retain the database release, access date, mapping method, thresholds, candidate-to-reference table, unresolved matches, and hashes. Keep provider data in approved external storage.

Sources: [PMN 17 release](https://plantcyc.org/pmn-17-released/), [PMN downloads](https://plantcyc.org/downloads/), and [P450Rdb publication](https://pubmed.ncbi.nlm.nih.gov/37871773/).
