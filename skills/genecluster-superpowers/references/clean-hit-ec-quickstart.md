# CLEAN and HIT-EC quickstart

**Status:** planned.

Public sources are available for [CLEAN](https://github.com/tttianhao/CLEAN), [CLEAN-Contact](https://github.com/PNNL-CompBio/CLEAN-Contact), and [HIT-EC](https://github.com/datax-lab/HIT-EC). This repository does not yet make an end-to-end integration claim.

Before adoption, add a public or synthetic protein fixture, pin exact code and model revisions, verify licenses, define a compact prediction and abstention schema, and compare predictions with independent evidence.

Do not commit private sequences, model credentials, weights, or caches.
