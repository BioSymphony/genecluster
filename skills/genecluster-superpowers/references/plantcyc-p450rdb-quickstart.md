# Plant Metabolic Network and P450 references quickstart

**Status:** PMN 17 is current as of 2026-08-30 and remains subject to provider terms. Check P450 reference sources at access time.

Obtain PMN data through the provider's current [download process](https://plantcyc.org/downloads/). Do not commit or redistribute gated data. Record release, access date, provider identifier, allowed use, mapping method, thresholds, unresolved matches, and hashes.

Use stable identifiers and tiny synthetic rows in public examples. Reference matches are supporting evidence and do not establish function in a new species by themselves.
