# Plant Metabolic Network and P450 references

Use Plant Metabolic Network (PMN) release 17 for reference pathway records. Check whether a pathway entry is curated or predicted. P450Rdb v2.0 provides curated P450 reactions and separate model predictions. Record the evidence type with each match. [PMN 17 release](https://plantcyc.org/pmn-17-released/) · [P450Rdb v2.0](https://www.cellknowledge.com.cn/p450rdb_v2/index.html)

## Access boundary

Use PMN's license form for full database exports. Its download page lists separate tabular files and amino-acid FASTA sets. P450Rdb lists v2.0 downloads for academic research and offline analysis. Check redistribution terms before sharing provider data. [PMN downloads](https://plantcyc.org/downloads/) · [P450Rdb downloads](https://www.cellknowledge.com.cn/p450rdb_v2/download.html)

Public examples should use stable identifiers and tiny synthetic rows rather than copied provider datasets.

## Output contract

Retain the database release, access date, mapping method, thresholds, candidate-to-reference table, unresolved matches, and hashes. Keep provider data in approved external storage.

[P450Rdb publication](https://pubmed.ncbi.nlm.nih.gov/37871773/)
