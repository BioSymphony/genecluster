# Implementation plan

This plan tracks public GeneCluster improvements.

## Phase 0: Public foundation

- maintain the public repository boundary;
- keep examples public or synthetic;
- run static path, secret, artifact, link, and mirror checks;
- document security reporting and contribution rules.

## Phase 1: Campaign contracts

- define manifests and ledgers;
- define route cards and claim limits;
- provide tracker-neutral work-unit templates;
- provide solo-agent prompts.

## Phase 2: Evidence and review

- normalize candidate and cluster outputs;
- preserve tool disagreement;
- add claim checks;
- build accessible tables, figures, and review pages.

## Phase 3: External execution

- define portable launch manifests;
- require immutable images and verified downloads;
- use least-privilege identities;
- return only approved summaries;
- verify cleanup.

## Phase 4: Tool integration

- add public fixtures;
- record exact versions and output contracts;
- update the tool knowledge base;
- promote a tool only after its public fixture passes.
